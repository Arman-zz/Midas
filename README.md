# MIDAS

A React and JavaScript implementation of the MIDAS marketplace prototype.

## Features

- Public, customer, shop-owner, and admin views
- Persistent English/Bangla language switch
- Hash-based navigation, dialogs, notices, forms, and demo actions
- Feature-based `src` structure with pages, layouts, components, hooks, context,
  services, data, utilities, model constants, and assets

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
